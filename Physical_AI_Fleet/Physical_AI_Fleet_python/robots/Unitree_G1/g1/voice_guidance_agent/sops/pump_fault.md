# Pump Fault Troubleshooting
Tools: multimeter, hex key set, vibration meter
Safety: lock out and tag out power before opening the pump housing.
1. Switch off the pump and apply lockout tagout.
2. Check the motor terminals with the multimeter for 415 volts.
3. Inspect coupling bolts with the hex key set and retighten.
4. Check bearing vibration with the vibration meter, limit 7 millimeters per second.
5. If vibration is above limit, replace the bearing and report to the supervisor.
