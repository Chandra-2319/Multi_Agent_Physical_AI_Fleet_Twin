# Motor Overheating
Tools: infrared thermometer, multimeter, cleaning brush
Safety: lock out and tag out before touching the motor.
1. Measure the casing temperature with the infrared thermometer, limit 90 degrees.
2. Switch off the motor and apply lockout tagout.
3. Clean the cooling fins with the brush.
4. Check the supply current with the multimeter against the nameplate.
5. If still hot after restart, report to the supervisor.
